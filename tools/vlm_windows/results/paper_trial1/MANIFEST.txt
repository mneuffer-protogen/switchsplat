SwitchSplat VLM interaction windows used by every paper experiment

These 12 files are byte-identical to <scene>/vlm_prediction.txt in the public SwitchSplat
dataset (the pinhole and fisheye copies are identical).

rollout:          GPT-5.6 Sol through Codex CLI 0.148.0, reasoning effort max, trial 1
                  (raw answers: results/gpt-5.6-sol/max/trial1/<scene>/raw_observation.json)
which rollout:    the first max-effort rollout. When these files were exported (2026-08-21)
                  three max-effort rollouts existed and trial 1 agreed best with the annotated
                  interaction times; trials 4-10 were run on 2026-08-23. Of all ten max-effort
                  rollouts it is still the most accurate: 59/59 annotated windows matched,
                  0 extras, 0 misses, endpoint MAE 2.559 frames.
post-processing:  postprocess.py defaults: drop windows shorter than 20 frames, then
                  confidence-ranked temporal NMS at IoU 0.8
